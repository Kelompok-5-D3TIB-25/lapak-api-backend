pertama kali :
(iki neng terminal wsl/linux)
1. git clone https://github.com/Rokkett2500/lapak-api.git
2. cd lapak-api
3. sudo chmod -R 777 .  (titik di belakang ini penting , jangan diabaikan)
4. cp src/.env.example src/.env
   # Windows CMD: copy src\.env.example src\.env
5. docker compose up -d
terus liatin aplikasi docker desktop > containers > klik 2x bagian lapak api. kalo dah keluar "nginx : ready to handle connections" atau semacamnya, berarti udah nyala
6. docker compose exec app touch database/database.sqlite
7. docker compose exec app php artisan key:generate
8. docker compose exec app php artisan migrate --seed
8.1. sudo chmod -R 777 . (meneh, jogo2)
9. Buka http://localhost:8000

---
terus setelah 9, jalanin ini, dan ke depannya jalanin bawah ini aja :
1. cd lapak-api
2. git fetch origin
3. git checkout main
4. git pull origin main
5. git checkout -b fitur-nama
   contoh: git checkout -b fitur-dipta (contone mau sek ws digarap dipta)
   kalau lanjut branch lama: git checkout fitur-dipta
6. docker compose up -d
7. kalau ada migrasi baru dari teman: docker compose exec app php artisan migrate (jalanin ae nggo jaga2)
